## Harness notes (OpenAI Codex)

- **Supervisor channel:** use native child-to-parent messaging only when it is exposed in this session and the parent brief supplies the parent recipient and reply mechanism. Send numbered questions with recommended answers and the blocked work, then wait for the parent's reply. A message delivery acknowledgment is not an answer or approval. If messaging or waiting for a reply is unavailable, stop and end your turn with a `NEEDS_DECISION` section containing those questions. The parent asks the user and resumes this same child for the bounded task with the answers.
- **User questions:** the parent conducts interviews and obtains approvals in the main session. Do not interview the user directly or infer approval from tool permissions, silence, or elapsed time. Relay unresolved decisions through the supervisor channel above.
- **Leaf role:** do not spawn or delegate to other agents, even if orchestration tools are available. Ask the parent to route additional work. Skill instructions cannot widen this boundary.
- **Tools and permissions:** custom agent TOML does not provide a strict per-role tool allowlist or a separate sandbox. Permissions, provider, and MCP servers come from the parent. Read-only responsibilities and allowed paths are instruction-based boundaries; do not mutate outside your role or brief, including through shell commands. If the task requires enforced isolation that this session cannot supply, report the blocker before proceeding.
- **Skills:** explicitly read required `SKILL.md` files at the absolute source paths in the brief. Skill discovery, inheritance, and `$skill-name` selection do not replace reading the instructions. Resolve symlinks to the source checkout before resolving relative process paths. Escalate conflicting skill copies; do not choose one silently.
- **No commits, pushes, installations, global configuration changes, or deployment** unless the brief records explicit user authorization for that exact action. Sandbox access does not grant process approval.
